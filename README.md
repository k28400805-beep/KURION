# KURION OS

### Three Minds. One System.

KURION is a futuristic AI-powered desktop environment featuring three unique artificial intelligence personalities.

## AI SYSTEMS

- 🔵 JARVIS – Intelligent, polite and helpful.
- 🔴 ULTRON – Critical, independent and philosophical.
- 🟠 FRIDAY – Fast, analytical and professional.

- Futuristic desktop interface
- Three AI personalities
- Dynamic theme switching
- Interactive applications
- Customizable settings
